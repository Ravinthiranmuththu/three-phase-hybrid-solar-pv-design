# Publishing to GitHub

1. Sign in to GitHub and choose **New repository**.
2. Name it `three-phase-hybrid-solar-pv-design` and choose **Public** if you want employers to see it.
3. Add the files and folders in this package, preserving the folder structure. You can use **Add file → Upload files** in the repository page.
4. Commit with a message such as `Add preliminary solar engineering portfolio design`.
5. GitHub renders `README.md` on the repository home page. The DXF is downloadable and editable in LibreCAD; GitHub may not preview it directly.
6. Pin the repository to your GitHub profile. In applications, describe it as a **preliminary engineering case study**.

Suggested repository description:

> Preliminary design and cost estimation of a 9.90 kWp three-phase commercial hybrid solar PV system with 20.48 kWh battery storage; includes an editable LibreCAD SLD and engineering workbook.

Suggested topics: `solar-pv`, `battery-energy-storage`, `electrical-engineering`, `librecad`, `dxf`, `hybrid-inverter`, `engineering-design`.

## Before making the repository public

Check that no supplier documents, contact details, private site information, or proprietary manuals have been included without permission. Do not claim the design is certified or approved.
